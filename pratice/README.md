# Go 單元練習題

題目依專案的 01～17 單元設計。每個 `exXX` 目錄都是獨立程式，詳細題目
寫在該目錄的 `main.go` 中。

## 作答規則

- 情境、名稱、數字及輸出文字可以自行設計。
- 題目中的資料只是參考，不是唯一答案。
- 標示為「核心要求」的 Go 觀念必須出現在答案中。
- 至少測試一個正常案例及一個邊界或錯誤案例。
- 除非題目明確限制，型別與函式名稱可以自行調整。

## 執行方式

在專案根目錄執行：

```powershell
go run ./pratice/ex01
```

練習其他題目時，把 `ex01` 替換成對應題號。
